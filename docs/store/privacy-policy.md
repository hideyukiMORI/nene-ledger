# NeNe Ledger のプライバシーポリシー / Privacy Policy

最終更新 / Last updated: 2026-11-09

## 日本語

NeNe Ledger（以下「本アプリ」）は、利用者の個人情報を集めません。

- 本アプリは通信しません。開いたファイルの中身・操作の記録・利用の統計を、作者を含むどこへも送りません
- アカウントの登録はありません。広告はありません
- 本アプリが書くのは、利用者が保存したファイル（とその保存のための一時ファイル）と、利用者の PC の中の設定のファイル（配色・文字の大きさ・検索の条件など）だけです。設定のファイルは、Microsoft Store から入れた場合はアプリを消すと一緒に消えます
- クリップボードは、利用者がコピー・切り取り・貼り付けを行ったときだけ使います

この方針を変えるときは、このページを更新し、変更の日付を書きます。問い合わせは GitHub の Issue へ：<https://github.com/hideyukiMORI/nene-ledger/issues>

## English

NeNe Ledger ("the app") does not collect any personal information.

- The app does not use the network. It never sends the contents of your files, your actions or usage statistics anywhere, including to the author.
- There is no account and there are no ads.
- The app writes only the files you save (and the temporary file used to save them safely) and a settings file on your PC (theme, text size, search options and similar). When installed from the Microsoft Store, the settings file is removed together with the app.
- The clipboard is used only when you copy, cut or paste.

If this policy changes, this page will be updated with a new date. Questions: GitHub Issues — <https://github.com/hideyukiMORI/nene-ledger/issues>
