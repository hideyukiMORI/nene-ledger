## 短い説明（ストアの検索結果に出る・200 字まで）

大きな CSV / TSV を開いた瞬間に表で見せ、触っていない所は 1 バイトも変えずに直して保存する、表のエディターです。先頭の 0 や日付に見える値も、書いてあるとおりのまま。

## 説明

【プレビュー版（早期アクセス）です】最初の正式な版の前に、触ってもらうために出しています。まだ足りない機能があります。大事なファイルは写しを作ってから試してください。

NeNe Ledger は、CSV と TSV のための表のエディターです。Excel で CSV を開くと、先頭の 0 が消えたり、日付や長い数字が勝手に書き換わったりします。NeNe Ledger は値を文字列のまま扱い、表示でも保存でも変えません。触っていない行は、保存しても 1 バイトも変わりません。

■ 大きなファイルでもすぐ開く
1 GB・1,000 万行を超えるファイルでも、最初の画面はすぐ出ます。行の数え上げと索引作りは裏で進みます。

■ 読み方を自動で判別して、選び直せる
区切り（カンマ・タブ・セミコロンほか）、文字コード（UTF-8・Shift_JIS・UTF-16・EUC-JP ほか）、引用符の流派、見出しの行を判別します。違っていれば、パレットから選んでその場で試し、開き直せます。

■ 直して保存する
セルを直す（打ち始め・F2・ダブルクリック・日本語の入力）、行と列を足す・消す、元に戻す・やり直す（保存の後も）、名前を付けて保存。Excel から複数のセルをそのまま貼り付け、切り取りもできます。

■ 探す・置き換える
全角半角・大文字小文字・ひらがなカタカナの区別を選んで探せます。正規表現も使えます。全部を置き換える前に「何が何に変わるか」を見せ、値の一部だけが変わるセル（980 を 990 にしたら 1980 も変わる、など）を注意します。Ctrl+Z 1 回で全部戻ります。

■ 壊れた行に気づける
列の数が見出しと違う行は、行の番号が赤くなり、次・前の壊れた行へ飛べます。範囲の合計に壊れた行が入れば、そう添えます。

■ キーボードだけで使える
Ctrl+Shift+P で全部の操作を名前で探せます（漢字・かな・ローマ字・英語）。125 の配色、OS の明暗と高コントラスト、文字の大きさに対応しています。

■ 通信しません
アカウントも広告もありません。ファイルの中身を外へ送りません。
