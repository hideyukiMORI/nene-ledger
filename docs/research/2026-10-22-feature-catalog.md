# 機能の一覧 — CSV / TSV エディターに要るもの

> Issue #3 / 2026-10-22。4 つの調査と [ペルソナ討議](2026-10-22-persona-discussion.md) から起こした一覧。**SPECIFICATION の FR ではない。** どれを FR にするかは施主が決め、別の Issue で SPECIFICATION に反映する。
>
> - **優先**: Must（無いと約束が成り立たない）/ Should（初版に入れたい）/ Could（後の版）/ Won't（やらない）。討議の合意による**提案**
> - **競合**: 調べた競合で持つものの多さ。多（ほぼ全部）/ 一部 / 少（1〜2 製品）/ 無（見つからない）
> - **根拠**: 文献 = [規格と落とし穴](2026-10-22-standards-and-pitfalls.md)・速さ = [速さの比較](2026-10-22-benchmarks.md)・競合 = [競合](2026-10-22-competitors.md)・要望 = [利用者の要望](2026-10-22-user-needs.md)・討議 = [討議](2026-10-22-persona-discussion.md) の論点
> - **FR**: 既にある FR。「新」は SPECIFICATION にまだ無い

## 25. やらないこと（Won't）とその理由

| 機能 | 理由 |
| --- | --- |
| 型の自動の推し量りと自動の変換 | 製品の約束（FR-003）の否定 |
| 数式・セルの書式・複数のシート | 表計算ではない（SPECIFICATION 第 3 節） |
| クラウド・共同編集・AI・テレメトリ・Web / API からの取り込み | データを外に送らない（SEC-05） |
| 外部の分析エンジン（DuckDB 等）の組み込み | ADR 0007 |
| スクリプト言語の組み込み | 依存が大きい。手順の記録（AUTO-01）で繰り返しの要望に応える |
| 地図のプレビュー | 範囲外。座標は文字列のまま保つ（KEEP-01） |
| xlsx / Parquet（初版） | SPECIFICATION 第 3 節。施主の判断で見直す |

## 27. 施主に判断してほしいこと
