## 0.1.0-preview.1 から変わったこと

### 検索と置換が使いやすく、事故に気づけるように

- **置換の欄は「探す」「置換後」の 2 つ**を縦に並べ、打っている欄が分かるようにしました。Ctrl+H は探す欄から始まり、前に探した文字は選んだ状態で入ります（打てば置き換わります）。
- **条件（大小を区別・セル全体・正規表現・全角半角を区別・ひら/カタを区別）は札**になり、オンは ✓ と色で分かります。札を押しても切り替わります。
- **全部の置換の前に「何が何に変わるか」**を見せます。980 を 990 にしたら 1980 も 1990 になる、のような**値の一部だけが変わるセルは赤で必ず**知らせます。全角半角などを区別せずに「No.1」を探して「Ｎｏ．１」にも当たるときも赤で知らせます。その場で条件を替えれば数え直します。
- **列を選んで（Ctrl+Space）から Ctrl+F・Ctrl+H を開くと、その列だけを探して置き換えます**。欄に「範囲：商品名」と出ます。説明文などほかの列を巻き込みません。
- 当たったセルが検索の箱の下に隠れないよう、表を送るか箱を下へ寄せます。見つからないときは、オンの条件を添えて欄の中で知らせます。

### コマンドパレット

- **漢字・かなでも操作を引けます**（「置換」「検索」「テーマ」「文字化け」など）。何も打っていないときは**最近使った操作**が上に並びます。
- 文字コードや区切りを試す間は箱が下へ寄り、試した表の先頭の行が見えます。文字コードには「Windows・Excel の日本語」などの注が付きます。
- 開いている間に Ctrl+F・Ctrl+H・Ctrl+G・Ctrl+Shift+P を押すと、閉じずにその段へ替わります。
- 行へ飛ぶ（Ctrl+G）の欄に、表の行と列の範囲が出ます。

### 表の画面

- **列の数が見出しと違う行（壊れた行）**は、行の番号が赤くなり、詳細ペインに「6 列・見出しは 5 列」と出ます。**F8 / Shift+F8** で次・前の壊れた行へ飛べます。ファイル全体の数は状態の行に「列の数が違う行 2（F8）」と出ます。範囲の合計に壊れた行が入れば、そう添えます。
- 状態の行の行の数は「データ 5,000 行（見出し 1 行）」と、見出しを分けて数えます。
- 範囲の集計は、¥・桁区切り・指数などを読み替えて数にしたセルの数と、数の範囲（最小〜最大）・空のセルの数を添えます。
- 詳細ペインに、表の印（□ 全角の空白・→ タブ・¶ 改行）の名前と数が出ます。
- セルを直している間、長い値はセルを右へ広げて全体を見せます。直したセルの左には、保存するまで緑の帯が付きます。
- 済んだことは緑、注意は赤で知らせます（橙は確かめだけ）。

### 開く・保存

- **Ctrl+O でファイルを開けます**（新しい窓で）。ファイルを渡さずに起動して選ぶ画面をやめると、空の新しい表で始まります。
- ほかのアプリ（Excel など）が開いていて保存できないときは、「閉じてから Ctrl+S · 別名は Ctrl+Shift+S」と知らせます。
- 保存したら「保存しました（3 セル · Shift_JIS（CP932） · カンマ区切り · CRLF のまま）」と、書いた形を言います。
- Shift_JIS のファイルに表せない字（絵文字・𠮷 など）を入れると、詳細ペインでそう知らせます。保存はその字で止まり、どのセルか（行目・列目）を言います。
- 判別に迷ったときは、迷った 2 つの読み方の名前を言います。
- 窓にアプリのアイコンが付きました（タスクバーと Alt+Tab）。

## まだのこと（主なもの）

- 並べ替え・絞り込み・列の要約、列の変換、取り込み先の規則での検査、集計パレット
- 壊れた行の隔離と手直し、保存の前に表せない字を全部一覧で見せる検査、文字コードや方言を変えて書き出す
- 表示の言語の切り替え（今は日本語だけ）
- 検索の範囲を選んだセルの範囲に限る（今は列全体だけ）、置換のプレビューの表
- Microsoft Store での配布（準備中）

## 開き方

zip を展開して `nene-ledger.exe` に CSV を落とすか、exe を開いてファイルを選びます。**電子署名がない**ので、Windows が「Windows によって PC が保護されました」と止めたら「詳細情報」→「実行」を押してください。中身の説明は zip の `README.txt` にあります。
