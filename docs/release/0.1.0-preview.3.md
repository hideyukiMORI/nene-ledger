## 0.1.0-preview.2 から変わったこと

### 詳細ペインで、長い値をそのまま直せる

- **ペインの本文を押すと、Excel の数式バーのようにペインで直せます**。押した所にカーソルが置かれ、ドラッグや Shift+クリックで選べます。打っている間は、確定する前の日本語に下線が付きます。
- **ダブルクリックで語、3 回押すと行**を選びます（語は漢字・ひらがな・カタカナ・英数字の続きで切ります）。
- **F6 で、字を打つ先を表のセルとペインで替えます**。直していないときに F6 を押すと、ペインで直し始めます（閉じていれば開きます）。
- 直している欄（セルでもペインでも）の中で、選んだ字を **Ctrl+C でコピー、Ctrl+X で切り取り**できます。
- ペインの本文の上ではマウスのカーソルが I 字になります。
- **表との境の線を掴んで、ペインの高さを変えられます**（次の起動でも覚えています。ダブルクリックで元の高さ）。
- 長い値は、指をペインの上に置いてホイールを回すとスクロールします。右に細いスクロールバーが出ます。

### コマンドパレットが見つけやすく

- **タイトルバーの左端に「≡ 操作」のボタン**を置きました。押すと操作の一覧が開きます。右下の「F1 · Ctrl+Shift+P で操作の一覧」を押しても開きます。
- 何も打っていないときは、「よく使う」と分類の見出しの付いた目録が出ます。候補が多ければスクロールバーが出て、ホイールでも動かせます。
- 並べ替え・フィルター・印刷など、まだ無い機能を打つと、まだ無いと知らせます。

### 表の画面

- 列の数が足りない行の「セルが無い」所は、薄い市松の模様で示します（空のセルと見分けられます）。
- アプリのアイコンを作り直しました（値の箱と琥珀のカンマ）。

## まだのこと（主なもの）

- 並べ替え・絞り込み・列の要約、列の変換、取り込み先の規則での検査、集計パレット
- 壊れた行の隔離と、元のバイト列での手直し、保存の前に表せない字を全部一覧で見せる検査、文字コードや方言を変えて書き出す
- 表示の言語の切り替え（今は日本語だけ）
- 検索の範囲を選んだセルの範囲に限る（今は列全体だけ）、置換のプレビューの表
- Microsoft Store での配布（準備中）

## 開き方

zip を展開して `nene-ledger.exe` に CSV を落とすか、exe を開いてファイルを選びます。**電子署名がない**ので、Windows が「Windows によって PC が保護されました」と止めたら「詳細情報」→「実行」を押してください。中身の説明は zip の `README.txt` にあります。
