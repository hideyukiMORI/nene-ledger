# ADR 0034 — 見出しは続いた 1〜3 行の範囲で、列の名前は「 / 」でつなぐ

- 状態: 受理（2026-11-08・施主が「行の数を選べるようにする」を選んだ）
- 日付: 2026-11-08
- Issue: #277（GitHub）
- 影響する規則: OPEN-11 / VIEW-01 / ARC-011 / ADR 0024 / ADR 0027 / ADR 0033

## 文脈

見出しは「レコードの番号 1 つ」（`Option<u64>`）で、次の所がそれを前提にしている:

- 本体の番目とレコードの番号の写像（`body_mapping`）。見出しより後ろは 1 つずれる
- `Document` の見出しの行（`Option<ViewRow>`）と、列を足し消ししたときに並べ直す原本のセル
- 上に固定した行の高さ・当たり判定・IME の候補の窓の位置（「固定した行は 1 行」）
- 読み方の選び直しの候補（`ReadingChoice::Header(Option<u64>)`）
- 原本から裏で読む検索・置換・集計（見出しのレコードを飛ばす）

表計算から書き出した CSV には、見出しが 2 行以上に分かれたものがある（1 行目に「売上」、2 行目に「今年」「前年」）。今は 1 行しか固定できないので、2 行目はデータの 1 行目に見え、並べ替え・集計・検索の答えに混ざる。

## 決定

### 1. 見出しは、続いた 1〜3 行の範囲（core の `HeaderRows`）

- `HeaderRows { first, count }`（`count` は 1〜3）。作るのは `HeaderRows::new` だけで、範囲の外は `None`
- 見出しを表していた `Option<u64>` を全部 `Option<HeaderRows>` に置き換える。1 行の見出しは `count` が 1 のもの（第 2 の表し方を残さない）
- 見出しの行は行の並びの中で続いている。前書きと本体には行を足し消しできるが、見出しの行の間には足せない（見出しの行は選べないので、足す所が見出しの間にならない）。保存の後も続いたまま

### 2. 全部上に固定し、本体から除く

- 固定した行の数は見出しの行の数（無ければ列の番号の 1 行）。高さ・当たり判定・1 画面の行の数・IME の候補の窓は、この数から計る
- どの見出しの行を押しても、その列全体を選ぶ（1 行のときと同じ）
- 行番号の欄には、それぞれのレコードの番号を出す

### 3. 列の名前は各行の値を「 / 」でつなぐ

- 詳細ペインの見出しなど、列の名前を 1 つの文字列で言う所は、見出しの各行のその列の値を上から「 / 」でつなぐ。空の値は飛ばす（「売上 / 今年」・左の「売上」が結合で 1 列目にしか無ければ 2 列目は「前年」）
- 結合したセルを右へ伸ばして補うことはしない（ファイルにない値を作らない）
- 列の幅は見出しの全部の行の値から決める（今の 1 行のときと同じ規則）

### 4. 選ぶのは利用者

- 「見出しの行を選ぶ…」の候補は「見出しなし」と、最初の行（1〜10 行目）× 行の数（1〜3）。名前は「2 行目が見出し」「2〜3 行目が見出し」
- 判別は今までどおり 1 行（自動で 2 行以上と推さない）

### 5. 強制

- core の `HeaderRows` の正例・反例、`body_mapping` の 2〜3 行の写像のテスト（`make test`）
- `Document` のテスト: 2 行の見出しが両方固定され、本体・コピー・集計・行の数から除かれ、列の名前が「 / 」でつながる
- app のテスト: 原本から裏で読む検索・置換・集計が見出しの全部の行を飛ばす

## 却下した案

- **見出しは 1 行のまま、2 行目からは前書きと同じく本体に残す**: 2 行目がデータに混ざる問題が残る
- **2 行目以降を見出しの「補足」として別に持つ（`Option<u64>` ＋ 追加の行）**: 見出しの表し方が 2 つになり、写像・裏の処理・保存の後の置き直しの全部で 2 つを合わせる必要がある（ARC-001）
- **固定するのは最後の 1 行だけで、名前だけつなぐ**: 施主の選んだ「全部上に固定」と違う。上の行が見えないと、つないだ名前の元が画面で分からない

## 結果

- `Option<u64>` の見出しを渡していた所（application の写像・表・読み方の候補、app の開く・読む・検索・置換・集計）の型が変わる
- 見出しの行は 4 行以上にできない。必要になったら `HeaderRows::MAX` を変える（固定した行が本体を押し出しすぎないかを測ってから）
