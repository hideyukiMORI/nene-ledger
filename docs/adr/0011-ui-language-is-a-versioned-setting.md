# ADR 0011 — 表示言語は 6 言語の閉じた集合で、文言は core の 1 表から出し、希望は版付きの設定に残して OS の観測値で解決する

- 状態: 受理
- 日付: 2026-10-22
- Issue: #6
- 影響する規則: ARC-001 / ARC-004 / ARC-007 / ARC-009 / ARC-011 / RS-002 / CNF-012 / QLT-013。FR-034 を足す

## 文脈

施主の要望（2026-10-22）: 「多言語化とカラーリングテーマも同様に導入してね」。「同様に」は NeNeDocket の ADR 0011 を指す。NeNeDocket は 6 言語を core の 1 表で持ち、希望を版付きの設定に残し、OS の言語を起動時に 1 度観測した。
NeNe Ledger は文言が NeNeDocket より多くなる（方言の名前・一括処理の進み具合・検証の違反・変換の名前）。それでも語の集合は閉じている。

制約: core / application は既定のロケール・環境変数を読まない（ARC-007）。UI に文字列を書かない（ARC-011）。閉じた `enum` の `match` に `_` を書かない（RS-002）。

## 決定

**表示言語は `Language`（日本語・English・简体中文・繁體中文・한국어・Español）の閉じた集合。画面の語は `Word`（閉じた集合）で名指しし、core の `wording::text(language, word)` の 1 表だけが文字列を持つ。希望は `LanguageChoice`（`system` か決まった言語）として版付きの設定に残し、表示する言語は希望と起動時に観測した OS の言語から純関数で解決する。**

1. **言語の集合**（決め打ちしない）: `ja` `en` `zh-hans` `zh-hant` `ko` `es`。足すときは `Language` の変種と `wording` の関数を 1 つ足す（網羅性でコンパイルが落ちる）。選択肢には各言語の自分の名前を出す
2. **文言の表は core**。言語ごとに 1 関数（`Word` の `match`）。数を含む文は `Word` の引数で組み、語順の違いも表の側で持つ
3. **希望と表示の分離**: 設定は `language = system|<tag>`。`system` は OS の言語（分からなければ English）。起動後の OS の変更には追従しない
4. **観測はアダプタの 1 か所**: X11 は `LC_ALL` → `LC_MESSAGES` → `LANG`、Windows は `GetUserDefaultLocaleName`。core の `Language::from_locale` で言語にする（`zh` は `hant` か台湾・香港・マカオなら繁体字）
5. **切り替え**はその場で全部の語が変わり、設定に書く。書けなければ示す（FR-023）
6. **字形**: Windows は DirectWrite に地域名（`ja-jp` `zh-cn` `zh-tw` `ko-kr` `en-us` `es-es`）を渡して fallback の字形を選ばせる。X11 は言語ごとの確かめる字（日・简・繁・한・A・ñ）を描ける家族を選び直す（NeNeDocket ADR 0007 / 0011 の継承）
7. **利用者のデータは言語に依らない**: セル・見出し・ファイル名は翻訳しない。数や日付の表示の書式（FR-009 の見方）は言語と別の設定にする（表示言語を変えても、数の小数点の記号は変わらない）

## 強制

- **active（実装後）**: `Word` と `Language` は閉じた `enum`。表に抜けがあればコンパイルが落ちる。全言語 × 全語が空でないテスト
- **active（実装後）**: core は環境変数を読めない（`#![no_std]`・CNF-012）
- **planned**: 画面の文字列のリテラルを UI と application から字句で拒む検査（CNF の追加は実装の Issue で検討）

## 結果

- 得るもの: 6 言語で同じ画面。文言は 1 か所。海外の利用者にも出せる
- 失うもの: 翻訳の確認。母語話者の確認が無い言語は「機械的に正しいが自然とは限らない」と明記する
- 残る穴: 右から左の言語（アラビア語など）は入れない（ADR 0002 の文字の整形は OS 任せ）

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| gettext / fluent などの外部の仕組み | 語の集合は閉じていて、表 1 つで足りる。外部クレートを増やさない（ARC-013） |
| 言語ごとのファイルを起動時に読む | 読めないファイルの扱いが増える。言語の集合は閉じているので表で持つ |
| 日本語と英語だけ | 施主が「同様に」（NeNeDocket の 6 言語）を求めた。費用は表の列が増えるだけ |
