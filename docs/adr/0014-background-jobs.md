# ADR 0014 — 重い処理は裏の一括処理。状態は application の純粋な状態機械、実行は scan / store のスレッド、結果は塊の順に合わせる

- 状態: 受理
- 日付: 2026-10-22
- Issue: #8
- 影響する規則: ARC-004 / ARC-005 / ARC-006 / ARC-007 / RS-009 / RS-016 / QLT-008 / CNF-012。FR-010・BIG-06

## 文脈

索引・検索・並べ替え・絞り込み・集計・変換・保存は、巨大なファイルでは秒から分かかる。画面を止めず、進み具合を見せ、中止できることが約束（FR-010）。
スレッドを持てるのは adapters・scan・store だけ（ARC-007・CNF-012）。core と application は `#![no_std]` で時間もスレッドも知らない。結果は何本のスレッドで動かしても同じでなければならない（ARC-007・QLT-008 の 2）。

## 決定

**一括処理の状態（何が走っていて、どこまで進み、中止を求められたか）は application の閉じた状態機械が持つ。実行は scan / store のスレッドが行い、application の `JobPort` を通して進み具合と結果を渡す。並列の結果は塊（チャンク）の順に合わせ、終わった順には合わせない。**

1. **状態**: `JobState` は閉じた `enum`（待ち・走っている（種類・進み具合）・中止を求めた・終わった・失敗した・中止した）。遷移は application の純関数。UI は状態を描くだけ
2. **実行**: scan（読み取り・索引・検索・並べ替え・集計）と store（保存・書き出し）が、`std::thread::scope` の作業スレッドで行う。スレッドの数は起動時に adapters が観測した論理 CPU の数を上限にする
3. **進み具合**: 処理したバイト数（か行数）/ 全体。作業スレッドが一定の間隔（塊ごと）で通知し、画面のスレッドは毎フレーム受け取る。通知が届いたら OS の合図で窓を起こす（X11 は `ClientMessage`、Windows は `PostMessage`。NeNeDocket ADR 0008 の形）
4. **中止**: 共有の中止の印（`AtomicBool`）を、作業スレッドが塊ごとに見る。中止した処理の途中の結果は捨てる（部分の結果を見せる処理は、その処理の Issue で決める）
5. **決定性**: ファイルを塊（境目は行の区切り・ADR 0017）に分けて並列に処理し、**結果は塊の番号の順に合わせる**。スレッドの数を 1 と N で変えて同じ結果が出るテストを、並列の処理ごとに置く（QLT-008 の 2）
6. **同時に走らせてよい組**: 読むだけの処理（索引・検索・統計）は同時に走ってよい。保存は排他（走っている間は、原本を読む処理と編集を止める）
7. **依存**: 当面 `rayon` などの並列のクレートは入れない。`std::thread::scope` と塊の分け方で足りるかを測り、足りなければ ADR で入れる

## 強制

- **active（既存）**: スレッドは adapters・scan・store の外で書けない（CNF-012）。遅延グローバル（`OnceLock` など）は書けない（CNF-002）
- **planned**: スレッドの数を変えて同じ結果のテスト（並列の処理を実装する Issue ごとに）
- **不能**: 「画面のスレッドで重い処理をしていないか」はレビューと実測（BIG-10 の 500 ms）で見る

## 結果

- 得るもの: どの重い処理も同じ形（状態・進み具合・中止）で扱える。結果がスレッドの数に依らない
- 失うもの: 塊の順に合わせるので、終わった順に合わせるより少し遅れる（最後の塊を待つ）
- 残る穴: 作業スレッドの中の panic は、全体を止めないように受け止めて「失敗した」にする（`std::thread::scope` の join の結果）。受け止め方は実装の Issue で決める

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 非同期のランタイム（tokio など） | 依存が大きく、計算の並列には向かない。ファイルの読み取りは塊ごとの同期で足りる |
| 最初から `rayon` | 便利だが依存。まず標準で書いて測る |
| 処理ごとにスレッドを作り放題にする | CPU を食い合い、画面が止まる。上限を置く |
| 終わった順に結果を合わせる | 結果がスレッドの数と速さで変わる（ARC-007） |
