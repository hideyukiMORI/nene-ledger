# ADR 0009 — ライセンスは独自: 使うのは自由、改変はクレジット必須、配布は無償に限り、販売は禁止

- 状態: 受理
- 日付: 2026-10-22
- Issue: #2
- 影響する規則: ARC-013

## 文脈

Issue #2 で依存の許可制（cargo-deny）を移植するとき、自分のクレートのライセンスが要った（証明 P-24 / P-25 は、自分のクレートのライセンスが許可の表に無いと落ちることを測る）。
施主の条件（2026-10-22）: 「利用は商用でも私用でも可能。改造する場合はクレジットは外せない。配布も自由だけれどお金をとっちゃダメ。アプリ自体を販売もダメ」。

## 決定

**独自のライセンス `LicenseRef-NeNe-Ledger-1.0` を [LICENSE](../../LICENSE) に置き、workspace の全クレートに付ける。**

1. 条文は英文を正とし、日本語の参考訳を添える
2. `Cargo.toml` の `[workspace.package] license` は SPDX の `LicenseRef-NeNe-Ledger-1.0`。`deny.toml` の `allow` は実測でこれだけ（外部の依存は 0）
3. 外部の依存を足すときは、その依存のライセンスが本ライセンスと両立するかも ADR で確かめる（とくに、配布の条件を課す copyleft のライセンスとは両立しない可能性がある）

## 強制

- **active**: `make deny` の許可制（P-24 / P-25 の実測・gate-proofs 第 3 節）
- **不能**: 条文の解釈・遵守。ライセンスは機械では守らせられない

## 結果

得られるもの:

- 施主の条件（使用は自由・クレジット必須・無償配布・販売禁止）を 1 か所に書ける
- 依存の許可制の証明がこのリポジトリのライセンスで成り立つ

失うもの・残る穴（**正直に**）:

- 🔴 **OSI の定義でいう「オープンソース」ではない**（再配布で料金を取ることを禁じるため）。オープンソースのライセンスを前提にした配布の場（一部のパッケージの置き場）には載せられない可能性がある
- 🔴 **独自の条文は法律の専門家の確認を経ていない。** 「料金を取る」の範囲（媒体代・サポート料・寄付）や「販売される製品に含める」の範囲は、紛争になれば解釈が割れうる
- copyleft（GPL など）の依存は、配布の条件が衝突しうる。依存を選ぶときに確かめる

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| MIT / Apache-2.0 | 販売を禁じられない |
| CC BY-NC 4.0 | ソフトウェア向けではなく、「非営利」の範囲が使用にも及ぶと読まれうる（施主は商用の使用を許したい） |
| PolyForm Noncommercial | 商用の使用そのものを制限する |
| ライセンスを付けない | 使用も改変も許されないと読まれる。施主の「使うのは自由」と合わない |
