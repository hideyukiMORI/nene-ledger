# ADR 0007 — 並べ替え・集計・統計は自前で作る。DuckDB などは組み込まず、比較相手として使う

- 状態: 受理
- 日付: 2026-10-22
- Issue: #1
- 影響する規則: ARC-013 / ARC-012 / QLT-014 / FR-009 / FR-012 / FR-013 / FR-014

## 文脈

ピボット・統計・列の参照（FR-012〜014）は、DuckDB を組み込めばすぐに作れて、速さも十分である。
施主との検討（2026-10-22）で、次の比較をした。

DuckDB を組み込む欠点:

- C++ で書かれた大きな依存が入る。配布が数十 MB 増え、ビルドも重くなる
- 読み込むときに型を推測する。「勝手に変えない」（FR-003）とぶつかる
- 編集中の差分・変換の規則（ADR 0005）と組み合わせにくい。渡すたびに変換が要る
- CSV に直接問い合わせると毎回読み直し、取り込むと時間と同じ大きさの複製がかかる

自前で作る利点:

- 最初に作った行の索引と、触った列のセルの位置をそのまま使い回せる
- 原本に差分を重ねたものを直接読める
- 全部文字列の前提なので、型の推測も変換も要らない
- 「操作した瞬間の速さ」（見えている範囲から先に返す・途中経過を逐次出す）に寄せられる

施主は「全部自前で作ったほうが高速化できる可能性は無いか」と問い、自前で作る方向に決めた（2026-10-22）。

## 決定

**並べ替え・絞り込み・集計・統計・参照・縦持ちと横持ちの変換を自前で作る。外部の分析エンジンは組み込まない。DuckDB・qsv・xsv・Modern CSV は、同じファイルで速さを比べる相手として使う。**

1. 規則（比較・集計・統計の定義）は core の純関数、実行（並列・一時ファイルへの退避）は scan
2. 速さのための手段の候補（実装の Issue で測って選ぶ）:
   - 一度使った列だけを列ごとの形（位置 ＋ 長さ）で記憶に残し、2 回目から解析をやり直さない
   - 種類の少ない列は値を番号に置き換えて（辞書化）集計と比較を整数で行う
   - 並べ替えはキーの先頭の数バイトによる基数ソートと、見えている範囲から先に返す部分ソート
   - 種類の数は HyperLogLog、分位点は t-digest で、メモリを一定に保って概算する（概算と示す・FR-012）
3. **性能の測定を最初から仕組みにする。** 同じファイルで「開く・並べ替える・集計する・絞り込む」の時間を、本製品と比較相手で測る道具と記録の形を、最初の性能の Issue で決める（QLT-014）
4. 比較相手の道具は、施主の作業フォルダの中で、開発の機械にだけ入れる。製品の依存にはしない
5. 自前で追いつけない凝った分析が要ると分かったら、「外部の道具で開く」形の出口を別の ADR で検討する（組み込みではなく、ファイルを渡すだけ）

## 強制

- **planned**: CNF-013（外部 crate の許可表に分析エンジンが無いこと）・`make deny`。QLT-014（測定の記録）は最初の性能の Issue で形を決める
- **不能**: 「自前のほうが速い」こと自体は機械では保証できない。測定の記録だけが根拠になる

## 結果

得られるもの:

- 依存が小さく保て、配布が 1 つの exe のまま
- 原本・差分・変換の規則と同じ土台の上で動く（ADR 0005）
- 型を推測しない前提を最後まで通せる

失うもの・残る穴（**正直に**）:

- 🔴 **汎用の分析エンジンとしての速さで DuckDB に勝つのは難しい。** ベクトル化した実行・記憶に入らない処理の退避・処理の組み合わせの最適化は、長年の積み重ねがある。エディターで使う範囲に絞って追いつく
- 🔴 **作る量が多い。** 統計・ピボット・参照・変換のそれぞれに、記憶の上限と一時ファイルへの退避が要る
- 「自前のほうが速い」は、測るまで主張しない（QLT-014）

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| DuckDB を組み込む | 上の文脈の 4 つの欠点。とくに型の推測が FR-003 とぶつかる |
| Polars を組み込む | Rust だが依存の木が非常に大きく、列の型を前提にする。差分との組み合わせも同じ問題 |
| SQLite に取り込んで SQL で処理する | 取り込みの時間と複製。分析向けではなく、巨大な集計は遅い |
| よく使う機能だけ自前、凝った分析は組み込んだ DuckDB に渡す | 組み込む時点で依存と配布の重さは同じ。出口が要るなら決定の 5 のように「ファイルを渡す」形にする |
