# 用語集 — NeNe Ledger

> Status: normative（規範）/ 2026-10-22 初版
> ここに載っている語は、コード・ドキュメント・Issue で**同じ意味**で使う。同義語を発明しない。
> 型／場所の欄は、まだコードが無いので**置く予定の名前**である。実装したら実名に直す。

| 語 | 意味 | 型／場所（予定） |
| --- | --- | --- |
| 原本（source） | 開いたファイルのバイト列。保存の置き換えまで書かない | `Source`（application）・scan が読む |
| 方言（dialect） | 原本の書き方: 文字コード・BOM・区切り文字・引用符・改行・見出しの有無 | `Dialect`（core）・FR-001 / FR-002 |
| 判別（detection） | 原本の先頭から方言を推し量ること。確信が無ければ候補を示す | `detect`（core の純関数） |
| 行（row） | 原本の 1 レコード。引用符の中の改行は行を分けない | `RowIndex`（core） |
| 列（column） | 行の中の何番目のセルか。見出しの文字列ではなく番号で指す | `ColumnIndex`（core） |
| セル（cell） | 行と列で決まる 1 つの値。**文字列であり、型を持たない** | `Cell`（core） |
| 見出し（header） | 先頭の行を列の名前として扱うかどうかと、その文字列 | `Dialect` の一部 |
| 壊れた行（malformed row） | 方言どおりに切れない行（閉じていない引用符など）。元のバイト列のまま保ち、示す | `RowShape`（core）・FR-023 |
| 参照実装 | セルの切り出しを素朴に正しく行う core の純関数。速い経路の正しさの基準 | core・ADR 0006 |
| 速い経路 | SIMD と並列で同じ切り出しを行う scan の実装。結果は参照実装と一致する | scan・ADR 0006 |
| 行の索引（row index） | 各行が原本の何バイト目から始まるかの表。裏で作る | `RowOffsets`（scan が作る） |
| 差分（overlay） | 原本に重ねる編集（セル・行・列の追加・削除・移動・書き換え）。保存まで原本を触らない | `Overlay`（core・application が持つ）・ADR 0005 |
| 変換の規則（transform） | 列にかける変換（大文字・小文字・空白・置換・日付の形式）。全セルを書き換えず、表示で計算し、保存で反映する | `Transform`（core）・FR-011 |
| 表の見え（view） | 並べ替え・絞り込み・列の幅と順・スクロール位置。原本も差分も変えない | `TableView`（application） |
| 比較の方法 | 並べ替えで値を「文字列として」「数として」「日付として」比べるかの選択。利用者が列ごとに選ぶ | `Ordering` 系の閉じた `enum`（core）・FR-009 |
| 一括処理（job） | 裏で動く重い処理（索引・並べ替え・絞り込み・集計・変換・保存）。進み具合と中止を持つ | `Job` / `JobState`（application）・FR-010 |
| 進み具合（progress） | 一括処理がどこまで進んだか。処理したバイト数か行数 | `Progress`（core） |
| 中止（cancel） | 利用者が一括処理を止める意図。途中の結果は捨てるか、部分として示す | `KeyIntent` の一種 |
| 保存（save） | 原本 ＋ 差分 ＋ 変換の規則から新しい内容を一時ファイルに書き、書き終えてから元のファイルと置き換えること。**その場の上書きではない** | store・ADR 0005 / FR-007 |
| 書き出し（export） | 方言を変えて別のファイルに書くこと。原本は変えない | store・FR-007 |
| 置き換え（replace） | 一時ファイルを元の名前にすること。Windows は `ReplaceFileW` と再試行、Linux は `rename` | store |
| 外部の変更 | 開いた後に他のプロセスが原本を書き換えたこと。検出して示す | FR-019・方式は ADR |
| 統計（statistics） | 列の件数・空欄・種類の数・最小・最大・平均・分位点。概算なら概算と示す | FR-012 |
| ピボット（pivot） | キーの列で行をまとめて集計した表 | FR-013 |
| 参照（lookup） | 別のファイルのキー列で値を引くこと | FR-014 |
| ポート（port） | 中核がプラットフォームを使うための型のある窓口 | `*Port`（application の `trait`） |
| アダプタ（adapter） | ポートの実装。時計・クリップボード・画面・IME・ごみ箱・印刷を中核へ渡す | adapters-x11 / adapters-windows |
| 合成ルート | 依存を結ぶ唯一の場所。端末と終了コードを持つ | `crates/app`（`main`） |
| フレームの入力 | 窓の大きさ・ポインタ・押された鍵・確定前の文字列。UI が OS のイベントから作る | `FrameInput`（application） |
| 表示フレーム | 最新の状態から生成する、描くための値の組（描画命令の列と倍率） | `LedgerFrame`（application） |
| 部品（widget） | 自前で描く UI の要素。矩形と状態と判定から描画命令を返す純関数 | core・NeNeDocket ADR 0006 の形を継ぐ予定 |
| 描画命令 | core が出し UI が描く列。塗り・縁・文字・切り抜き | `DrawCommand`（core） |
| 確定前の文字列（preedit） | IME が組み立て中の文字列。確定で差分になる | `Preedit`（core） |
| 隔離区画 | 可変性を許した唯一の場所 | ARC-005 の表 |
| 規約検査（conformance） | NeNe Ledger 固有の自作ゲート | `xtask`（CNF-NNN） |
| 抑制 | `#[expect(lint, reason = "<規則 ID>: …")]`。理由付きで、発火しなくなれば落ちる | RS-019 |
| 機械強制の状態 | active / planned / 不能 / 不採用 | `docs/QUALITY_GATES.md` の強制マトリクス |
| negative proof | ゲートが意図した規則で落ちることの実測 | `make prove` / `docs/quality/gate-proofs.md` |
| 機能（feature） | FEATURES.md の 1 行。変えない番号（`OPEN-01` など）・フェーズ・状態を持ち、ちょうど 1 つの FR に属する | `docs/FEATURES.md`・ADR 0008 |
| フェーズ（phase） | 機能を入れる順の目安。1 = 約束の芯・2 = 初版に続けて・3 = 後の版 | ADR 0008 |
| 手順（recipe） | 記録した操作の列。名前を付けて保存し、別のファイルへ再生する。独自の版付きテキスト | AUTO-01・ADR 0008 |
| 規則（rules） | 列の名前と順・必須・見方・長さ・選択肢などの書式の決まり。検証と書き出しに使い、ファイルとして共有する | VALD-02・ADR 0008 |
| Issue | 作業の単位。GitHub の Issue | ADR 0021・GIT-001 |
| PR | 統合の境界。本文の欄は `.github/pull_request_template.md` | ADR 0021・GIT-004 |
| 論理画素 | 物理画素 ÷（dpi / 96）。文字の大きさはこれで定める | core |
| 表示言語（language） | 画面の語の言語。6 つの閉じた集合。希望（`system` か決まった言語）は設定に、表示する言語は OS の観測値と合わせて解決する | `Language` / `LanguageChoice`（core）・ADR 0011 |
| 語（word）と文言の表 | 画面に出す語の名前と、言語ごとの文字列の表。UI は文字列を書かない | `Word` / `wording::text`（core） |
| 配色（theme） | 名前・明暗・画面の色。組み込み 125 の元（背景・前景・強調の 3 色と出典）から整数の補間で導く。希望（`system` か名前）は設定に | `Theme` / `ThemeSeed` / `ThemeChoice`（core）・ADR 0012 |
| 明暗（appearance） | ライトかダークか。OS の観測値と配色の表が持つ | `Appearance`（core） |
| 色の役割（paint） | 背景・面・字・強調・選択・交互の行・見出し・印・タイトルバーなど、色の意味。UI は役割から色を引く | `Paint`（core） |
| タイトルバー（title bar） | 窓の上の帯。アプリ名・ファイル名・未保存の印・最小化・最大化・閉じる。自前で描き、当たり判定は core | ADR 0013・WIN-01〜11 |
| 窓の縁（frame） | 窓の外周の、リサイズの当たり判定の帯。見えなくてもよい | ADR 0013 |

## 使ってはいけない語

`Manager` / `Helper` / `Util` / `Utils` / `Common` を型名の語尾に使わない（RS-013）。
役割を語る名前が思いつかないときは、その型が 2 つの責務を持っている可能性が高い。
「上書き保存」と言わない。保存は**置き換え**である（ADR 0005）。
「型」をセルについて使わない。セルは文字列で、数や日付として扱うのは**比較の方法**と**変換の規則**の側である。
